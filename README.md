### Практическая подготовка

В рамках подготовки PT Start были отработаны лабораторные сценарии по:

- Security Monitoring и SIEM;
- Windows Event Logs, Sysmon и audit policy;
- Linux security logging;
- сетевому анализу и Wireshark;
- Active Directory;
- web security и penetration testing.

> Эти направления описывают практическую подготовку и не являются дословным содержанием сертификата.
